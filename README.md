# منصة المحاكاة الكيميائية - مدرسة المهيني

## الملفات
- `index.html` الرئيسية، `grade.html` الصف، `semester.html` الفصل، `staff.html` الهيئة، `contact.html` التواصل
- `data/data.js` كل البطاقات والبيانات
- `models/g10|g11|g12/s1|s2/` ملفات نماذج المحاكاة (اختياري، يمكن أيضًا رفع الملف من لوحة الأدمن)

## التشغيل
افتح `index.html` مباشرة للمعاينة، أو ارفع المشروع على GitHub ثم اربطه بـ Vercel (Add New > Project).

## الحفظ التلقائي (مرة واحدة)
1. أنشئ مستودعًا على GitHub وارفع محتوى هذا المجلد وانشره على Vercel.
2. GitHub > Settings > Developer settings > Fine-grained tokens > Generate: اختر المستودع فقط، وصلاحية Contents = Read and write.
3. في المنصة: أدمن (1214) > أيقونة الخروج > "الحفظ التلقائي (GitHub)" وأدخل المستودع (user/repo) والفرع والتوكن.
4. بعدها أي تعديل يُحفظ تلقائيًا ويظهر للزوار خلال دقيقة تقريبًا بعد إعادة النشر.

التوكن يُخزَّن في متصفحك أنت فقط. بدون إعداد GitHub تُحفظ التعديلات كمسودة في متصفحك ويمكنك تنزيل `data.js` احتياطيًا واستبدال الملف.

كلمة مرور الأدمن مكتوبة في `data.js` وهي ليست حماية حقيقية.

`data/wisdom.js` قائمة الحكم والنصائح في الشريط العلوي، يمكنك إضافة أي عبارة جديدة بنفس الصيغة.
